x-cli is a high-performance open-source AI coding agent. It runs natively on macOS and Linux (and on Windows via WSL2), profiles your hardware to pick the right local model, and switches to cloud providers when you want it.

## What you get

- **One binary, one command.** `curl … | bash` then `x-cli`.
- **Local by default.** A custom Rust inference engine (ICN, llama.cpp under the hood) runs models on your GPU. Nothing leaves your machine.
- **Cloud when you want it.** OpenAI, Anthropic, NVIDIA NIM, Ollama, or any OpenAI-compatible endpoint — same runtime, same tools.
- **Real platform.** A typed package graph with a daemon protocol (ACN), event-sourced agent runtime, and a built-in OpenTelemetry collector (Motel).
